# Student Registration Form

## Objective

Create a Student Registration Form using HTML and CSS to collect student details and display submitted students' information in a table.

## Task Description

Build a student registration webpage that includes a registration form and a table displaying dummy student data.

## HTML Features

- Student Registration Form heading
- Full Name input field
- Email input field
- Password input field
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth input field
- Register submit button
- Horizontal line separator
- Submitted Students (Dummy Data) heading
- Student details displayed in a table

## CSS Styling

- Universal selector to apply Arial, Helvetica, and sans-serif fonts.
- Body background color set to whitesmoke with a margin of 20px.
- Heading styled with black text and bottom margin.
- Text, email, password, and DOB input selectors styled with width, padding, border, and bottom margin.
- Table, input, and label elements styled with a font size of 16px.
- Labels displayed as inline-block with bottom margin.
- Register button styled with a blue background, white text, padding, and pointer cursor.
- Button hover effect changes the background color.
- Input focus effect changes the border color to blue and removes the outline.
- Table borders collapsed for a clean layout.
- Table header styled with a blue background and white text.
- Table row hover effect changes the background color.
- Table header and data cells styled with borders.
